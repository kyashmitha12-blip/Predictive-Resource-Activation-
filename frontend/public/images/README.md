# Landing page photographs

The landing page shows a real photograph when these files exist, and falls back to live campus listings when they do not.
Add licensed or self-shot photos (JPEG, about 1600px wide, under 300 KB each):

- `hero.jpg`    : students using shared equipment (landscape, 4:3 or 3:2)
- `why.jpg`     : a lab bench, workshop or collaborative space (landscape)

Use images you own or that are licensed for reuse. Do not hot-link.
